# MADHYUM CRM
Mobile-first PWA prototype for MADHYUM GROUP.

## Current build
- Premium mobile dashboard
- Add inquiry
- Local device persistence via localStorage
- Five MADHYUM wings
- PWA manifest + offline service worker

## Important
This is a front-end prototype. Production CRM still requires secure authentication, cloud database/backend, roles/permissions, real follow-up engine, members/partners/reports, and security testing.
